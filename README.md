# gamefit-lab
ゲーミングPC・デバイスの投資優先順位を診断する検証サイト
---

## 診断イメージ

### 例：VALORANTを240fpsで快適に遊びたい

現在の環境：

- CPU：Ryzen 5クラス
- GPU：RTX 4060クラス
- メモリ：16GB
- モニター：フルHD / 144Hz
- 追加予算：50,000円

GameFit Labでは、単純に高価なPCへの買い替えを勧めるのではなく、現在の構成と目的から投資優先順位を考えます。

この例では、

1. モニターのアップグレード
2. 必要に応じてメモリ増設
3. GPU・PC本体は現状維持を検討

というように、「次の1円をどこへ使うと効果が大きいか」を判断します。

実際の性能はゲーム設定、ドライバ、アップデート、PC構成等によって変動するため、最終的な購入時には各メーカーの公式仕様をご確認ください。

## 運営方針

GameFit Labは、ゲーミングPC・PCパーツ・モニター・マウス・キーボードなどについて、ゲーム用途と予算から費用対効果の高い選択肢を考える情報サイトです。

高額な商品を購入すること自体を目的とせず、「現状維持」「一部だけ交換」「PCを買い替える」の選択肢を含めて比較します。

## 広告・アフィリエイトについて

当サイトでは、商品・サービスの紹介にアフィリエイトプログラムを利用する場合があります。

掲載されたリンクを経由して商品・サービスが購入された場合、当サイトが紹介料を受け取ることがあります。

ただし、広告報酬の有無だけを理由に商品を推奨することはせず、利用目的、性能、価格、費用対効果を重視して情報を掲載します。

## プライバシーについて

当サイトでは匿名の利用状況分析にPostHogを使用し、診断改善のためページ閲覧、診断利用、ゲーム種別、FPS帯、予算帯、推奨結果等を取得する場合があります。

診断では氏名・メールアドレス等を取得せず、CPU / GPUの自由入力内容も分析データとして送信しません。

アフィリエイトサービス等の利用に伴い、Cookie等の技術が使用される場合がありますが、当サイトがCookieによって氏名・住所等の個人情報を直接取得することを目的とするものではありません。

外部サービスにおける情報の取り扱いについては、各サービス提供者のプライバシーポリシーをご確認ください。
