# 日本語ネイティブ品質・UI最終監査

監査日: 2026-10-10

対象: Draft PR #1 / `feature/personal-gear-intelligence-v1`

範囲: 公開トップ、簡易診断、ガイド8本、非公開Personal Gear Intelligence、運営者用検証画面、404、関連するプライバシー・Affiliate表示

## 日本語品質の総合判定

**日本語品質はGO、独立10人の非公開検証はTEST、mainへの統合・公開はHOLD。**

主要画面は「結論 → 主な理由 → 必要な人向けの詳細」の順に読み進められる。内部enum、製品ID、点数、EvidenceのA〜D評価を利用者向けの結論として露出しない。日本語の自然さと表示崩れにP0/P1は残っていないが、実ユーザーが迷わず理解できるかは10人検証の実測前である。

## 修正した不自然な日本語

- 「PC買替」を「PCの買い替え」、「現在FPS」を「現在のFPS」、「モニターHz」を「モニターのリフレッシュレート」へ統一した。
- 初出の「RAM」を「メモリ（RAM）」、以後を「メモリ」とした。
- 診断結果を、点数の高低ではなく、確認すべき設定・候補・注意点が伝わる短い文章へ変更した。
- 「再読込」など機械的な省略を避け、「再読み込み」「回答を保存」など操作結果が分かる表現にした。
- 404を日本語化し、トップと診断への戻り先を示した。

## AIっぽさを削除した箇所

- 「最適」「おすすめ」「改善する」と断定していた箇所を、確認済みの条件に応じた「比較候補」「確認してください」「可能性があります」へ変更した。
- 製品カードから総合点と内部スコアを外し、好みとの一致、懸念、根拠、互換性、買わずに試せることを分けた。
- 情報量を本人との相性や満足の保証として見せない注意書きを追加した。
- 情報不足時は製品IDを代替表示せず、「製品名を確認できません」として運営者確認へ戻す。

## 英語ラベル見直し

- `My Setup Lite / Gear Taste / Game / Input / Next Upgrade / Regret Shield / Why Not?` は、参加者画面では「現在の機材 / 好み / ゲーム・操作方法 / 買い替え候補 / 後悔しそうな点 / 合わない理由」に置き換えた。
- `SAFE / BETTER_FIT / AVOID / DONT_UPGRADE / CLARIFY` などの内部値は保存・計測用に維持し、表示だけを日本語化した。
- 390px幅では工程名を「機材 / 好み / 条件 / 結果 / 調整」に短縮し、内部値は表示しない。

## 表記統一

表示語彙、単位、判断ラベル、禁止表現を `docs/ui-copy-ja.md` に集約した。単位は数値との間に半角スペースを置き、FPS、Hz、GBを統一する。`confidence` は「判断材料の多さ」、`evidence grade` は文字等級ではなく「十分 / おおむね十分 / 一部のみ / 不足」と表示する。

## 信頼感に関する修正

- 診断で「精度」「正解率」「AIが最適化」など、Outcome未取得の段階で裏付けられない表現を使わない。
- DONT_UPGRADEを失敗や消極案にせず、「買い替えを急がなくてよい」と理由を添える。
- 互換性・根拠・本人の好みが不足する場合は、購入候補を断定せず確認へ戻す。
- 公開診断の結果は簡易な比較材料であり、性能向上や満足を保証しないことを明記した。

## UI/UX不備

修正済み:

- 診断結果の点数表示と、不必要な順位競争を削除。
- 長い判断文、ボタン、工程表示の390px横あふれを防止。
- プライバシー説明は要点を先に示し、保持期間などの詳細を折りたたみ表示にした。
- 参加者の「自分のデータを削除」と、運営者が管理する匿名検証記録の削除範囲を分離した。
- フィードバック保存失敗時に、成功したように見える通知が残らないようにした。

実ブラウザ確認:

- 1440×1000と390×844で、公開診断、非公開フロー、運営者画面、404に横スクロールなし。
- 非公開フローは「現在の機材 → 好み → ゲーム・操作方法 → 結果 → 合わない理由 → 再提案」まで完了。
- ブラウザコンソールのerror/warningは0件。非公開画面の外部リソース要求は0件。
- 破壊的な削除操作とexport/recoveryは今回の目視では再実行せず、自動テストで範囲と失敗経路を確認した。

## 技術的不備

- 参加者データ削除で10人検証台帳まで消える不備を修正した。
- localStorageへの保存失敗を捕捉し、既存データを壊さず読み取り専用へ退避する経路を維持した。
- ローカル表示ではPostHogを初期化しないガードを追加した。
- 表示用コピーを `ui-copy-ja.js` に分離し、内部enumと計測値を変えずに日本語化した。
- Playwrightは既存依存に含まれないため追加していない。既存のブラウザsmokeスクリプトは保持し、今回はCodex内ブラウザで代替確認した。

## Privacy / Affiliate表現

- 非公開画面は名前・メール・自由記述を求めず、localStorageだけを使用し、自動外部送信がないことを明示した。
- 現在の機材と好みは削除操作まで、判断・フィードバック履歴は365日、検証台帳は運営者画面を開いた時点で30日超を削除する境界を明記した。
- exportしたJSONは10人検証終了後30日以内に運営者が手動削除する。共有端末では利用しない注意を表示した。
- Affiliateは診断順位に使わない。リンクがない現状と、将来報酬を受け取る場合も結果・順番へ反映しない方針を公開画面とガイドで説明した。
- 外部レビュー本文、画像、表、グラフ、動画、サムネイルは転載していない。出典はURLと短い独自factに限定する既存方針を維持した。

## ⑤メジャー

- `diagnosis_started`、`diagnosis_completed`、ガイドCTA、共有、Affiliate CTAなど既存イベント名と許可済みpropertyを維持した。

- 非公開Personal Gear Intelligenceには外部Analyticsを追加していない。10人検証は匿名のローカル台帳で測る。

- Privacy、Affiliate、Evidence、rights境界が実装と表示で矛盾していないことを確認した。
- 外部調査は競合の構造確認に使用し、文章・画像・独自表をコピーしていない。

## ②スカウト

日本語圏の比較・診断系サイトでは、範囲、根拠、更新、運営主体、広告関係が見えるほど安心材料になりやすい。確認対象は[パソコン工房の選び方](https://www.pc-koubou.jp/pc/howto_choose_gaming_pc.php)、[ギアセン](https://gearsen.com/)、[Device LAB](https://device-lab.jp/)、[MOUSE DX](https://www.mouse-dx.com/about)、[ちくわの穴](https://chikuwanoana.com/)、[マイベスト](https://my-best.com/462)。広告表示の基準は[消費者庁のステルスマーケティングQ&A](https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing/)を確認した。

GameFitの差別化候補は、一般的な「おすすめ順位」ではなく、買わない判断、設定確認を先に出すこと、人気製品でも本人に合わない理由を示すことにある。ただし差別化が利用者に伝わるかは、独立10人の理解度で検証する必要がある。
