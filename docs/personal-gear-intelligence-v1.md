# GameFit Personal Gear Intelligence v1

This feature branch defines the next-stage architecture without changing production behavior.

Core rule: product recommendation quality and affiliate monetization are separate layers. Affiliate availability never changes recommendation order.

Planned layers: Wide Catalog, Product Facts, Evidence Engine, Game DNA, My Setup, Gear Taste, Preference Detective, Weakest Link / Next Upgrade, Upgrade Match, Regret Shield, Budget Optimizer, Gear Atlas / Device Radar, Gear Watch / Buy Window, and post-purchase feedback.

No production deployment, paid API, scraping, account system, or email delivery is added by this branch.
