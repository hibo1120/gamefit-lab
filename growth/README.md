# GameFit Growth Pack v1

SEO以外の入口を30日間テストするための、投稿前素材と運用台帳です。ここにある素材はすべて下書きで、SNSへの投稿や予約投稿は行っていません。

## 収録内容

- `youtube-shorts.md`: 顔出し不要・字幕またはAI音声向けのShorts台本12本
- `x-posts.md`: 価値提供24本、診断CTA6本を基本にしたX投稿30本
- `note/`: 意思決定を助けるnote記事6本
- `content_calendar.csv`: 30日分・合計48コンテンツの投稿候補日
- `international-opportunity.md`: 英語版を検討するときの公開前チェックリスト

## IDとUTM

| 媒体 | ID | UTM |
| --- | --- | --- |
| YouTube Shorts | `yt_s01`〜`yt_s12` | `utm_source=youtube&utm_medium=shorts` |
| X | `x_01`〜`x_30` | `utm_source=x&utm_medium=social` |
| note | `note_01`〜`note_06` | `utm_source=note&utm_medium=article` |

全リンクの`utm_campaign`は`gamefit_growth_v1`、`utm_content`と`source`は各content IDです。媒体別に`diagnosis_page_viewed → diagnosis_started → diagnosis_completed → affiliate_clicked`を比較できます。

## 投稿前の扱い

1. 内容と最新のゲーム・製品事情を人間が確認する。
2. 公開先に合わせて改行、文字数、サムネイルを調整する。
3. `content_calendar.csv`の`status`を`approved`にしてから手動投稿する。
4. 投稿後に公開URLと投稿日を別の運用台帳へ記録する。

商品の型番、価格、Affiliate URLは入れていません。公式動作環境とGameFit独自の判断は、投稿でも混同しないでください。
