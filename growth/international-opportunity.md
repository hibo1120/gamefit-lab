# GameFit 英語版・公開前チェックリスト

英語サイトはまだ公開しない。この文書は、日本語版で流入と診断利用を確認した後に、英語圏向け検証の作業範囲を見積もるためのもの。

## 翻訳対象

- [ ] 診断フォーム、入力補足、結果カテゴリ、エラー、共有文を翻訳する
- [ ] 4ゲームの表示名、注記、GameFit独自判断を自然な英語へ置き換える
- [ ] 広告、免責、プライバシー、Analytics説明を対象地域に合わせて再作成する
- [ ] ガイド、タイトル、description、OG文言を直訳ではなく検索意図に合わせる
- [ ] 日本語の略語や「コスパ」を、意味が伝わる表現へ置き換える
- [ ] 英語ネイティブまたは対象市場を理解する人が最終レビューする

## URL構造

- [ ] `/en/`配下にするか、別ドメインにするかを公開前に決める
- [ ] 日本語版と英語版を混在させず、言語切替を双方向に用意する
- [ ] `hreflang="ja"` / `hreflang="en"` / `x-default`を設計する
- [ ] canonicalを各言語の正規URLへ向ける
- [ ] 英語URLをsitemapへ追加し、日本語URLのslugを機械的に流用しない
- [ ] 未完成ページはindexさせない

## SEO

- [ ] 米国・英国など対象国ごとに検索語と競合SERPを再調査する
- [ ] “gaming PC upgrade”, “monitor vs GPU”, “upgrade or replace”などの意図を確認する
- [ ] 日本の予算記事を単純換算せず、現地価格帯と購入行動に合わせる
- [ ] title、description、見出し、内部リンク、OGPを英語版として作る
- [ ] Search Consoleまたは相当ツールを言語・地域別に確認する

## Affiliateの地域差

- [ ] 広告主が対象国のユーザー、通貨、配送に対応するか確認する
- [ ] Amazon等の国別プログラムを混同せず、地域別merchant設定を分離する
- [ ] リンク先の地域、言語、在庫、返品条件を確認する
- [ ] 報酬条件、Cookie期間、商標ルール、広告表示義務を地域ごとに確認する
- [ ] 地域判定で自動転送する場合も、ユーザーが遷移先を理解できる表示にする
- [ ] 承認前のmerchantは`enabled: false`のままにする

## 単位・価格

- [ ] 円固定の予算選択をUSD等へ置き換え、換算値ではなく現地の意味ある価格帯を設定する
- [ ] 税込・税別、送料、為替変動を明示する
- [ ] 日付表記、小数点、桁区切りをlocale対応にする
- [ ] モニターHz、FPS、RAM/ストレージ容量は共通でも、PCモデルと電源規格の地域差を確認する

## ゲーム名・データ

- [ ] 公式の英語表記、地域別公式動作環境URL、対応プラットフォームを使う
- [ ] パッチや描画設定による差を保証値として書かない
- [ ] Monster Hunter Wilds等の商標表記を公式に合わせる
- [ ] ゲームごとの高FPS用途と重量級用途の説明を英語圏向けに見直す
- [ ] 日本語版と診断ルールを共有する場合も、地域別予算ロジックは分離する

## 法的・運用表記

- [ ] 対象国の広告開示、Affiliate disclosure、消費者保護、Cookie同意要件を専門家に確認する
- [ ] Privacy PolicyにAnalyticsの保存地域・送信項目・拒否方法を記載する
- [ ] 利用規約、免責、年齢要件、問い合わせ窓口を対象地域に合わせる
- [ ] GDPR、UK GDPR、CCPA/CPRA等の適用可能性を公開前に確認する
- [ ] 「公式推奨」とGameFit独自判断を見た目と文言の両方で区別する
- [ ] 英語版のQA、Analytics、404、アクセシビリティ、モバイル表示を独立して確認する

## 検討開始の目安

日本語版で媒体別の診断開始・完了が継続的に発生し、どの訴求が反応を得るか説明できること。英語化は翻訳作業ではなく、地域別の価格・広告・法的要件を持つ別プロダクトとして小さく検証する。
